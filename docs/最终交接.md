## 1. C7：方法论理解证据

本项目复刻的是老师项目“先安全上电与独立出声，再让声音服从时间轴，最后让网页成为指挥台”的推进方法，而不是复制老师代码。对应证据如下：

- `a-band-of-one-prd/a-band-of-one-prd.html` §01、§09：说明从老师四阶段方法抽象出的本项目 P0'→P1'→P2'→P3' 路线。
- `flow/plan.md`：记录 T03-U、P1'、P2'、P3'、T06 的依赖、停止门和验收标准。
- `docs/技术方案.md` §2、§4、§6：记录 GPIO8 安全边界、I2S 唯一时间源、板端状态真相、USB-Serial/JTAG 与网页分工。
- `flow/tasks/T03-T06-Luna执行.md`：记录各阶段的宿主测试、ASCII 构建、烧录和真机交接证据。

最终边界：板端负责发声、判定、严格拍长、节奏灯和状态；网页负责 Web Serial、乐谱事务、模式/音量请求与显示；正常产品不启用 HID、BLE HID 或 EasyInput App。
